# 🎉 College Fest Website

## 📖 Project Description

The College Fest Website is a static web application developed using HTML and CSS. It provides information about a technical festival (Tech Fest 2K26), including event details, featured competitions, gallery, organizers, registration form, event schedule, sponsors, FAQs, and contact information.

---

## 🚀 Features

- Responsive Navigation Bar
- Tech Fest Hero Section
- About Event Section
- Featured Events
  - Coding Contest
  - Web Design Competition
  - Quiz Competition
  - Paper Presentation
- Event Gallery
- Organizers Section
- Student Reviews
- Event Schedule
- Registration Form
- Sponsors Section
- FAQ Section
- Contact Information
- Social Media Links
- Footer Section

---

## 🛠️ Technologies Used

- HTML5
- CSS3
